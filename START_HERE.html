GEAR STUDIO · GETTING STARTED · 0.2.0

From download to your first gear.

Gear Studio runs inside Autodesk Fusion on Windows or macOS. It creates editable solid gears in your Fusion design. This page guides you through downloading, linking the add-in, creating a gear and editing it.

Download Gear Studio ZIP

You need Fusion desktop installed and working. The ZIP route needs no terminal, Git, installer script or separate Python installation.

01 · Download and extract

Work from an extracted folder.

  1. Save your designs and close Fusion.
  2. Use the Download button above, or open the GitHub repository and choose Code → Download ZIP.
  3. In Windows File Explorer, right-click the ZIP and choose Extract All → Extract. On macOS, double-click the ZIP in Finder.
  4. Open the extracted folders until README.md, START_HERE.html and the GearStudio folder are visible together. This is the project folder. Windows may create an extra outer folder with the same name.
Check before continuingYou can see a normal GearStudio folder outside the compressed ZIP. Double-click START_HERE.html to reopen these instructions in your browser at any time.
02 · Keep the project in Documents

Give Fusion a permanent location.

  1. Open Documents using the File Explorer or Finder sidebar. This also works if Documents is stored under OneDrive.
  2. Create a folder called FusionAddins.
  3. Move the whole project folder from step 1 into FusionAddins and rename it fusion-gear-add-on.
  4. Open its inner GearStudio folder. It must directly contain GearStudio.py and GearStudio.manifest.

03 · Link and run the add-in

Start Gear Studio inside Fusion.

  1. Open Fusion and a new design in the Design workspace.
  2. Choose Utilities → Add-Ins → Scripts and Add-Ins. If needed, press S and search for Scripts and Add-Ins.
  3. In the newer dialog, select All scripts and add-ins, click +, then Script or add-in from device. In the older dialog, select the Add-Ins tab and click its + button.
  4. Select Documents / FusionAddins / fusion-gear-add-on / GearStudio. Select the folder itself, not the outer project folder or an individual file.
  5. Select GearStudio in the list and click Run. Once it works, enable Run on Startup.
Check before continuingThe Gear Studio panel opens. At normal panel widths, the connection label says Autodesk Fusion. It must not show an Interface preview banner. The Getting started button in the panel shows the loaded version and folder.
Script, add-in, installer: which is this?

An add-in stays loaded to provide the panel and editing commands. A script runs a task and finishes. Gear Studio is an add-in. The .ps1 and .command files are optional file-copy installers for an alternative location; they are not used in these Documents instructions. Double-clicking GearStudio.py or index.html does not start the Fusion add-in.

04 · Create and save

Make a simple Spur gear first.

  1. Use a new Part or Hybrid design. In older Fusion releases, use a normal new Design. Finish any active sketch or command.
  2. Check that the design timeline is visible. If history is disabled, right-click the top design component in Fusion's Browser and choose Capture Design History. A pure Assembly design cannot receive these bodies.
  3. Choose Spur in Gear Studio and use the starter settings below. Give it a name such as Drive gear.
  4. Wait for validation. Correct any highlighted fields, then click Create gear once.
  5. Look in Fusion's canvas and Browser for the new solid. A Hybrid design gets a gear component; a Part design gets a body in its root component. Use Fusion's Fit view if the body is outside your current view.
  6. Save the Fusion design so the solid and its editable definition are retained.

Do I need to export the gear?

Create gear adds the B-rep to your active Fusion design. Save preserves that design, including Gear Studio's editable definition. Use Fusion's Export command only when you need another file format, such as STEP. Keep the original Fusion design for future Gear Studio edits.

05 · Edit an existing gear

Use the panel or the parameter table.

Change the gear in Gear Studio

  1. Select the generated body in Fusion's canvas or Browser.
  2. Click the refresh arrow in Gear Studio's selection box. Its name should appear.
  3. Click Edit, change Teeth to 30, wait for validation, and click Update gear.

Change the gear through Fusion Parameters

  1. Click Parameters at the bottom of Gear Studio, or open Modify → Change Parameters in Fusion.
  2. Under User Parameters, find Teeth_G1 and change its expression to 32. Your gear may use G2 or another number if other gears exist.
  3. Close the dialog. Select the body and refresh Gear Studio's selection.
  4. Click Update from Parameters in the Fusion parameters box below the input fields.
Parameter edits require an updateChanging a number in Fusion's parameter table does not automatically rebuild the gear. Update from Parameters applies those values after validation. Save the Fusion design when you finish.

Names start with their purpose: Module_G1, Teeth_G1, FaceWidth_G1 and Bore_G1. The G-number groups one gear's settings and remains stable when you rename the gear. Parameter comments identify the full gear name.

My existing parameters have long GS_ names

Select that gear's body and refresh the selection in Gear Studio. Click Shorten parameter names. This upgrades the names and saved references without rebuilding the solid. Existing long names remain supported until you choose this action. Use the add-in's action rather than manually renaming managed rows.

06 · Update later

Update the copy Fusion actually loads.

Check Getting started in the panel for its version and folder. Save your designs and fully close Fusion before replacing files.

If you downloaded a ZIP

  1. Download the latest ZIP and extract it separately.
  2. Rename your current project folder to an unused backup name, such as fusion-gear-add-on-backup.
  3. Put the new extracted project at Documents / FusionAddins / fusion-gear-add-on.
  4. Reopen Fusion and run GearStudio. Its existing folder link should still work because the path is unchanged. Check the version in Getting started.
  5. Keep the backup until the updated copy works.
I installed with Git instead

With Fusion closed, open the project folder in File Explorer, type powershell in its address bar and press Enter. Run git pull --ff-only. Reopen Fusion after it succeeds. This command only works in a Git checkout, not an extracted ZIP. The full installation guide includes the Documents-aware Git setup.

Saved gears remain in their Fusion documents. Last-used settings and presets are stored separately and survive code updates.

IF SOMETHING DOESN'T WORK

Find the step that stopped.

What you seeWhat to do
Nothing appears in Scripts and Add-InsAdd the inner GearStudio folder. Confirm GearStudio.py and GearStudio.manifest are directly inside it. Clear dialog filters.
PowerShell opens and closes, or its right-click option is missingUse the ZIP-and-link steps above. No PowerShell installer is needed.
A preview outline but no solidCheck the panel is running inside Fusion, wait for validation, then click Create gear. Read the status at the bottom if it fails.
Version looks old after updatingClose Fusion completely and check the installed path in Getting started. A second copy in Downloads or API/AddIns may still be loaded.
Parameter table changed but the solid did notSelect the gear, refresh selection, and use Update from Parameters.
The gear is off-screenUse Fit in Fusion and check the gear body and parent component visibility in the Browser.
A build or rename failsRetain the complete error, Fusion version, add-in version, loaded path and the input values. Follow any recovery instructions in the error.

Windows logs: paste %APPDATA%\GearStudio into File Explorer's address bar and open GearStudio.log. On macOS, use Finder → Go → Go to Folder and enter ~/Library/Application Support/GearStudio.
