QUICK START

Your first gear

  1. Open a design in Fusion.Use a new Hybrid design with Capture Design History enabled. Finish any active sketch or command.
  2. Start with a Spur gear.Use module 1 mm, 24 teeth, pressure angle 20°, face width 8 mm and bore 5 mm. Keep the other defaults.
  3. Check, then create.Wait for validation and click Create gear. The solid appears in Fusion's canvas and Browser. The 2D preview alone is not a created gear.
  4. Save and edit.Save the Fusion design. To change the gear later, select its body, click the refresh arrow here, choose Edit, change a value and click Update gear.
Change values in Fusion's Parameters dialog

Open Parameters using the button below the workspace. Edit a row such as Teeth_G1, then close the dialog, select the gear and choose Update from Parameters to validate and rebuild the full gear. An existing bore created or updated in 0.3.2 follows Bore_G1 directly; tooth geometry still needs Update.

For validation before geometry changes, edit in Gear Studio and use Update gear. Direct table edits use Fusion's solver immediately for the bore. Undo an invalid diameter; use the panel to add/remove a bore or change tooth size and bore together.

The G-number identifies a gear in this design. Names stay stable when you rename a gear. For older gears, select the body, refresh selection and choose Shorten parameter names.

Sketches, history and moving gears

New gears keep real sketches and operations. Expand the gear's Construction branch in the Browser and its named timeline group. Sketches are visible from the top-level Design workspace. Bore circles are centered and diameter-constrained; calculated cylindrical profiles and shaft references are locked in their local component. Edit gear inputs to change their shape.

Use Move/Copy → Move Object: Components and select the outer gear component to move the body and sketches together. Update gear rebuilds Construction and preserves the outer placement. After installing 0.3.2 and restarting Fusion, use Edit → Update gear once to constrain an older gear's sketches. Keep your own additions outside Construction; edits inside it are replaced. Broken external references abort an update.

New gears require a Hybrid design with history enabled. Existing Base Feature gears remain editable. Use Duplicate → Create gear to regenerate an independent copy with history. Existing face references are not transferred.

Install on another computer
  1. Download the GitHub repository ZIP and choose Extract All.
  2. Put the extracted project in Documents / FusionAddins / fusion-gear-add-on. It should directly contain README.md and the GearStudio folder.
  3. In Fusion, open Utilities → Add-Ins → Scripts and Add-Ins. Choose + → Script or add-in from device and select the inner GearStudio folder. In the older dialog, use the Add-Ins tab's + button.
  4. Select GearStudio, click Run, and enable Run on Startup after it works. Keep the linked folder in Documents.

Open START_HERE.html in the extracted project for the full illustrated folder check and instructions. The ZIP route needs no installer script, terminal or separate Python installation.

Create, save and export are different steps

Create gear makes a native B-rep inside the current design. Save in Fusion preserves the gear and its editable Gear Studio definition. Use Fusion's Export command when you need an interchange file such as STEP; the Gear Studio definition stays in the Fusion design.
